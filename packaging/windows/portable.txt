Pdfromeo portable mode

While this file sits next to pdfcraft.exe, Pdfromeo keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PdfromeoData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Pdfromeo with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Pdfromeo and
%LOCALAPPDATA%\Pdfromeo) instead. If PdfromeoData can't be written (for example on a read-only
drive), Pdfromeo says so and uses the per-user folders instead.
